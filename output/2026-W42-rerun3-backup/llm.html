2.8T LLM单卡推理与多模态扩散推理

AirLLM 展示 2.8T LLM 可在单张 4GB GPU 上完成推理，降低超大模型部署的显存门槛。Dual-Latent Memory Routing 针对多模态大模型在视觉-语言推理中随生成长度增加而性能下降的问题，提出双隐层记忆路由机制。LaViDa-R1 将推理能力推进到统一多模态扩散语言模型，为自回归之外的生成范式提供推理增强。三者共同覆盖大模型推理效率、长程视觉-语言记忆与扩散语言模型推理，对低成本部署和长上下文多模态任务具有直接价值。

MD-LLM-2：可迁移分子动力学语言模型

MD-LLM-2提出一种可迁移的分子动力学语言模型，并引入物理条件与显式路径概率。分子动力学模拟用于描述蛋白质在不同构象状态间的运动，但跨越自由能垒和采样多种热力学条件计算成本较高。此前MD-LLM-1表明语言模型可以更低成本生成构象轨迹，但需要为每个蛋白质单独建模。MD-LLM-2面向可迁移建模，旨在降低多条件构象采样的计算开销。

异构图像生成器共享潜空间接口

该工作提出InstantFusion，为异构图像生成器提供共享潜空间接口。扩散/流模型已成为图像生成的主流范式，并形成了架构与表示日益异构的生成器家族。尽管这些模型生成能力强，但跨模型潜表示对齐及其底层去噪动态的一致性仍缺乏研究。InstantFusion关注这一未充分探索的问题，通过共享潜接口连接不同图像生成器。该工作有助于处理异构生成模型之间的表示对齐与动态一致性问题。

概念归因解释黑盒视觉模型

该事件聚焦黑盒视觉模型的可解释性。解释机器学习模型预测是核心挑战，尤其对黑盒视觉模型。现有概念归因方法使用人类可理解概念来解释模型预测，但通常只能解释分类和回归模型。这些方法往往需要访问模型权重或大规模概念标注数据集，且多数方法存在解释能力局限。该事件以概念为中介，从概念层面解释黑盒视觉模型的预测，有助于提升视觉模型预测的可理解性。

DLLM-TTS: Block Discrete Diffusion Language Model for Text-to-Speech Synthesis
DLLM-TTS introduces a block discrete diffusion language model for TTS, balancing intelligibility and speed by combining masked diffusion within blocks and sequential block processing.
  • Block discrete diffusion over X-Codec2 tokens enables parallel token prediction within blocks, improving efficiency.
  • Sequential block processing maintains global text-speech alignment while local acoustic coherence is learned via masked diffusion.
  • Achieves competitive intelligibility with autoregressive models while offering faster inference (RTF).
